# @apnileap/contracts

This package contains the authoritative OpenAPI 3.x specifications for ApniLeap services:
- `openapi/common-envelope.yaml`: Standard `{data, meta}` / `{error, meta}` envelopes and error codes.
- `openapi/team-a.openapi.yaml`: Eligibility & scheduling service.
- `openapi/team-b.openapi.yaml`: Ranking & skill graph service.
- `openapi/team-c.openapi.yaml`: Data engine & transaction manager.
- `openapi/team-d.openapi.yaml`: BFF & UI endpoints.
